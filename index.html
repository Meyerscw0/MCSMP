Installed Modules

EssentialsXCORE
Homes, warps, kits, and /tpa. The backbone of day-to-day convenience — run /help in-game to see the full command list it adds.
GriefPreventionPROTECTION
Land claims via golden shovel. Protects builds and chests from other players — claimed ground can't be touched without permission.
CoreProtectPROTECTION
Logs every block change on the server. If something gets griefed or broken by accident, it can be rolled back to before it happened.
ChunkyPERFORMANCE
Pre-generates terrain so exploring never triggers laggy live chunk generation. Runs occasionally in the background, not per-session.
TABINTERFACE
Customizes the tab list — server name, player ping, and sort order. Purely cosmetic, no gameplay effect.
VaultINFRASTRUCTURE
No commands, no visible effect. It's the API other plugins hook into — installed now so an economy plugin can be added later without a rebuild.

Vanilla Tweaks · Active

Vanilla-compatible tweaks, not mods — no client-side install needed to see their effects.

AFK Display
Tags idle players in the tab list.
Armored Elytra
Throw a chestplate and an elytra onto an anvil (press Q to drop both on top) to merge them into one item with the armor's stats. To split them back apart, throw the merged item onto a grindstone.
Confetti Creepers
Creeper explosions burst into harmless confetti.
Double Shulker Shells
Shulkers drop two shells instead of one.
Dragon Drops
Adds extra loot options from the Ender Dragon fight.
Durability Ping
Warns in chat when a held item is close to breaking. Run /durabilityping set to adjust the warning threshold or sound.
Ender Chest Always Drops
Ender chests always drop when mined, tool or not.
Fast Leaf Decay
Cut leaves decay almost instantly instead of lingering.
Glass Always Drops
Glass and glass panes drop as items when broken.
Mini Blocks
Craft blocks into smaller versions with a stonecutter.
More Effective Tools
Expands what tools can correctly mine which blocks.
More Mob Heads
All mobs have a rare chance to drop their head.
Multiplayer Sleep
A percentage of players sleeping skips the night, not everyone.
Name Colors
Lets you set a custom color for your own name/nametag. Enter '/Trigger color' to see options.
Painting Picker
Place a painting item in a Stonecutter to browse and select the exact variant before placing it — no more random re-rolling.
Player Head Drops
Players drop their own head on death.
Wandering Trader Announcements
Chat message when a Wandering Trader spawns nearby.
Wandering Trades
